# Cybersecurity Frameworks (MITRE & NIST)

Use these mappings when classifying threats, designing defenses, or writing security reports:

- **MITRE ATT&CK:** Map attacker techniques (e.g., Initial Access, Execution, Persistence, Privilege Escalation, Credential Access, Lateral Movement, Exfiltration) to concrete code/infra paths.
- **MITRE D3FEND:** Pair every finding with a defensive countermeasure (Harden, Detect, Isolate, Deceive, Evict).
- **MITRE ATLAS (AI/ML & Agentic Systems):** Check prompt injection, indirect tool-output injection, excessive agency, model/data poisoning, and sensitive data leakage across agent boundaries.
- **NIST CSF 2.0:** Structure posture recommendations across *Govern, Identify, Protect, Detect, Respond, Recover*.
- **NIST AI RMF:** Evaluate AI components for validity, reliability, safety, security/resilience, and accountability.
